# FITLOG - Workout & Fitness Planner

A modern and responsive workout tracking web application. FITLOG helps you discover exercises, plan your daily fitness routines, and save workouts for later.

---

## 🛠️ Technologies Used

- **Next.js 16 (App Router)** - React framework for building server-side and client-side web apps.
- **React 19** - JavaScript library for building modern user interfaces.
- **Tailwind CSS & DaisyUI** - Modern utility-first styling with sleek dark mode design.
- **React Context API** - Global state management for workout plans and saved items.
- **React-Toastify** - Clean, responsive toast notifications for user actions.

---

## 🚀 5 Key Features

1. **Exercise Library**  
   Browse a wide collection of workouts with exercise images, difficulty levels, duration, calories burned, and user ratings.

2. **Dynamic Workout Details**  
   Click on any workout card to open a dedicated details page with equipment information and complete descriptions.

3. **Today's Plan & Saved Workouts**  
   Easily add workouts to "Today's Plan" or "Save for later" with a single click from the workout details page.

4. **Live Metrics Summary**  
   Track your fitness goals with automatic live calculations of total exercises, total minutes, and total calories burned.

5. **Interactive Actions & Notifications**  
   Mark workouts as done, remove items anytime, and get instant notifications with duplicate item warnings using React-Toastify.

## 💻 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/apu-22/A-06.git
cd A-06
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the app.
